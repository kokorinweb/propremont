# Проремонт

Лендинг вымышленного сервисного центра по ремонту телефонов во Владивостоке
(ТЦ «Луговая», ул. Луговая, 21а, бутик 221, 2 этаж).

Цель страницы одна — заявка: звонок, сообщение в мессенджер или форма. Каждый блок
ниже либо отвечает на вопрос клиента («сколько стоит», «можно ли доверять», «как найти»),
либо ведёт к заявке.

## Принципы

- **Цены видны сразу.** Формат «от 2 500 ₽ · 40 мин», а не «Уточнить».
- **Несколько каналов связи.** Телефон, Telegram, WhatsApp — не завязываемся на один мессенджер.
- **Форма короткая.** Дату и описание поломки уточнит менеджер.
- **Цены — только из одного источника данных.** Если появится ИИ-помощник, он не называет
  цены, которых нет в таблице.
