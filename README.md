# Проремонт

Лендинг сервисного центра по ремонту телефонов во Владивостоке
(ТЦ «Луговая», ул. Луговая, 21а, бутик 221, 2 этаж).

Цель страницы одна — заявка: звонок, сообщение в мессенджер или форма. Главное обещание —
**честная цена**: диагностика бесплатная, цена фиксируется в квитанции до начала ремонта.

## Запуск

```bash
npm install
cp .env.example .env.local   # токен бота и чат для заявок
npm run dev                  # http://localhost:3000
```

Без `TELEGRAM_BOT_TOKEN` сайт работает полностью, а заявки пишутся в лог сервера.
Проверки: `npm run typecheck`, `npm run build`.

## Что где

| Что | Где |
| --- | --- |
| Контакты, адрес, график, реквизиты | `src/lib/company.ts` |
| Цены, услуги, поломки для этикетки-оценки | `src/lib/prices.ts` |
| Отзывы (сейчас демо) | `src/lib/reviews.ts` |
| Вопросы и ответы | `src/lib/faq.ts` |
| Схема заявки (общая для формы и сервера) | `src/lib/request.ts` |
| Отправка заявки в Telegram | `src/lib/telegram.ts`, `src/app/api/request/route.ts` |
| Секции страницы | `src/components/*` |
| Политика конфиденциальности | `src/app/privacy/page.tsx` |

Цены заданы ровно в одном месте: этикетка в первом экране, прайс-чек, оценка в форме и
уведомление мастеру читают `prices.ts`, поэтому разъехаться им негде.

## Перед запуском — обязательно

Сайт готовится к реальному запуску, но сейчас в нём заглушки. Выдавать их за правду нельзя,
поэтому пока флаг `SITE_IS_DEMO` в `company.ts` включён: над шапкой висит полоса «Демо-версия»,
страница закрыта от индексации (`noindex`), а разметка для поисковиков и карт не выводится.
Выключать флаг последним, когда всё ниже закрыто.

- [ ] **Контакты и реквизиты** — телефон, Telegram, WhatsApp, e-mail, ИП, ИНН, ОГРНИП в `company.ts`.
- [ ] **Цены и сроки** — реальные цифры в `prices.ts`.
- [ ] **Обещания и условия** — оставить только то, что сервис реально выполняет. Сейчас на сайте
      обещано: гарантия до 6 месяцев на деталь и работу, талон с копией в мессенджер; ремонт от
      30 минут; запчасти на выбор (оригинал или копия); мастер работает за стеклом и отдаёт старую
      деталь; для большинства ремонтов не нужен пароль, файлы не открываем и не копируем; при
      неудачном ремонте клиент не платит и получает телефон в том же виде; оплата картой,
      наличными, переводом или по QR-коду; курьер по Владивостоку, выезд и ремонт на дому.
- [ ] **Отзывы** — заменить на настоящие (с согласия авторов) и выставить `REVIEWS_ARE_DEMO = false`
      в `reviews.ts`. Рейтинг 2ГИС показывать только настоящий.
- [ ] **Маршрут внутри ТЦ** — добавить в `company.ts` реальные ориентиры (вход, лестница, вывеска).
- [ ] **152-ФЗ** — политику проверить с юристом. Отдельный вопрос: заявки уходят в Telegram,
      это трансграничная передача персональных данных, а первичный сбор по закону должен идти
      в базу на территории РФ. Скорее всего, понадобится хранить заявки у себя до отправки в чат.
- [ ] **Фото** — настоящие снимки точки и мастера сильнее любой иллюстрации.
- [ ] `NEXT_PUBLIC_SITE_URL` — боевой домен (canonical, Open Graph, разметка).

## Дизайн

Направление «Запчасть и этикетка»: цена ремонта — это напечатанная этикетка. В первом экране
посетитель выбирает телефон и поломку, и «принтер» выдаёт термоэтикетку с ремонтом, ценой,
сроком, гарантией и настоящим штрихкодом Code 128 (`src/lib/barcode.ts`, сверен с JsBarcode).

- Розовый антистатического пакета — поле первого и последнего экрана, по верху двойная
  красная линия зиплока. Белые этикетки с чёрной печатью, чёрные поля для записи и подвала,
  жёлтый стикер — только предупреждения (демо).
- Fira Sans Extra Condensed прописными — голос этикетки (заголовки, цены), Golos Text — текст,
  Fira Mono — только коды, сроки и числа.
- Прайс печатается как чек, шаги ремонта — рулон этикеток, адрес — транспортная этикетка.

Дизайн вёлся по скиллу [impeccable](https://github.com/pbakaus/impeccable):
продуктовые факты — в `PRODUCT.md`, договорённость о направлении — в
`.impeccable/surfaces/src-app-page-tsx.md`. Скиллы для следующих сессий лежат в
`.claude/skills/` (impeccable, web-design-guidelines, vercel-react-best-practices), версии —
в `skills-lock.json`.
